# Приложение для анализа банковских транзакций

Проект представляет собой backend-модуль на Python для анализа личных финансов на основе выгрузки банковских операций (`operations.xlsx`). Приложение формирует JSON-данные для веб-интерфейса, анализирует выгодные категории повышенного кешбэка, строит отчеты по тратам с сохранением в файл и получает актуальные курсы валют и котировки акций S&P 500 через внешние API.

## Функционал проекта

1. **Веб-страницы (`src/views.py`)**
   - `main_page(date_str)` — формирует итоговый JSON для главной страницы:
     - приветствие в зависимости от времени суток;
     - статистика по каждой карте (последние 4 цифры, общая сумма расходов, начисленный кешбэк);
     - топ-5 транзакций по сумме платежа;
     - актуальные курсы валют к рублю (API ЦБ РФ);
     - актуальные цены акций из списка пользователя (`user_settings.json`, TradingView Scanner API).

2. **Сервисы (`src/services.py`)**
   - `analyze_cashback_categories(data, year, month)` — с использованием элементов функционального программирования (`filter`, `sorted`, `lambda`) анализирует расходы за указанный год и месяц и возвращает JSON с расчетом потенциального повышенного кешбэка (5%) по каждой категории.

3. **Отчеты (`src/reports.py`)**
   - `@report_to_file` — универсальный декоратор для функций-отчетов, который записывает результат работы функции в JSON-файл 
   - `spending_by_category(transactions, category, date)` — формирует `DataFrame` с тратами по заданной категории за последние 3 месяца от переданной (или текущей) даты.

4. **Вспомогательные функции (`src/utils.py`)**
   - Загрузка данных из Excel (`import_excel_data`), фильтрация по датам (`filter_by_date`), чтение пользовательских настроек (`get_user_settings`), запросы к API валют и акций.


## Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone <https://github.com/sergey0875/course_work.git>
   
   ```



3. **Установите зависимости:**
   

   *(Основные библиотеки: `pandas`, `openpyxl`, `requests`, `pytest`, `pytest-cov`, `dotenv` ).*
     Линтеры: `flake8`, `black`, `isort`
4. **Настройте `user_settings.json` в корне проекта:**
   ```json
   {
     "user_currencies": ["USD", "EUR"],
     "user_stocks": ["AAPL", "AMZN", "GOOGL", "MSFT", "TSLA"]
   }
   ```

5. **Запустите проект:**
   ```bash
   python main.py
   ```
